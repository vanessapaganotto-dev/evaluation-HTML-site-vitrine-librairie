# Librairie L'indépendante - Site Vitrine

## Description

Ce projet est un site vitrine pour la librairie **L'indépendante**, une librairie indépendante proposant une large sélection de livres dans divers genres : littérature, polars, poésie, philosophie, BD, etc.  
La page principale (accueil) présente la librairie, ses valeurs, une sélection du mois, ainsi que des liens vers d'autres pages du site.

Le design est simple et clair, avec un menu de navigation vers les différentes sections :  
- Accueil (page principale)  
- Présentation  
- Nos coups de cœur  
- Extraits choisis

---

## Structure du projet

- `index.html` : page d’accueil  
- `index_p2.html` : page de présentation  
- `index_p3.html` : page des coups de cœur  
- `index_p4.html` : page des extraits choisis  
- Dossier `css/` : fichiers CSS (`default.css`, `style_dev_02.css`)  
- Dossier `img/` : images utilisées dans le site (ex : `bandeau.jpg`, favicon)

---

## Fonctionnalités

- Menu de navigation simple et accessible  
- Mise en page avec titres, paragraphes et images  
- Liens vers les différentes sections du site  
- Footer avec adresse de contact  
- Utilisation des balises sémantiques HTML5 (`<address>`, `<nav>`, `<h1>`...)

---

## Installation et utilisation

1. Cloner ou télécharger le dépôt  
2. Ouvrir le fichier `index.html` dans un navigateur web moderne (Chrome, Firefox, Edge...)  
3. Naviguer à travers les pages via le menu pour découvrir la librairie et ses sélections
