# Librairie L'indépendante - Showcase Website

## Description

This project is a showcase website for **L'indépendante**, an independent bookstore offering a wide selection of books across various genres: literature, crime novels, poetry, philosophy, comics, etc.  
The main page (home) presents the bookstore, its values, a monthly selection, and links to other pages on the site.

The design is simple and clear, featuring a navigation menu linking to different sections:

- Home (main page)  
- Presentation  
- Staff Picks  
- Selected Excerpts

---

## Project Structure

- `index.html`: home page  
- `index_p2.html`: presentation page  
- `index_p3.html`: staff picks page  
- `index_p4.html`: selected excerpts page  
- `css/` folder: CSS files (`default.css`, `style_dev_02.css`)  
- `img/` folder: images used on the site (e.g., `bandeau.jpg`, favicon)

---

## Features

- Simple and accessible navigation menu  
- Layout with headings, paragraphs, and images  
- Links to different sections of the site  
- Footer with contact address  
- Use of semantic HTML5 tags (`<address>`, `<nav>`, `<h1>`, etc.)

---

## Installation and Usage

1. Clone or download the repository  
2. Open the `index.html` file in a modern web browser (Chrome, Firefox, Edge, etc.)  
3. Navigate through the pages via the menu to explore the bookstore and its selections
